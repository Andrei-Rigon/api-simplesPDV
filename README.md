# api-simplesPDV

Um pequeno gerenciador de vendas, com controle de Clientes, Produtos e Vendas.

# O que foi usado para instalação:

## Inicial project
nest new .

## Sequelize
npm install sequelize sequelize-typescript pg pg-hstore

## Pacotes baixados
npm install @nestjs/config
npm install sequelize sequelize-typescript pg pg-hstore
npm install @nestjs/sequelize sequelize sequelize-typescript
npm install --save @nestjs/jwt
npm i --save class-validator class-transformer
npm i bcrypt
npm i -D @types/bcrypt
